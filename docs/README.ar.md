# شعاع — Shuaa

منافسة نماذج بين **تركي ومهند ومازن** على نفس الصور الحرارية ونفس تقسيم البيانات.

[الموقع](https://turkialjutaili.github.io/Shuaa/) · [تعليمات إضافة نموذج](SUBMISSIONS.md) · [التوثيق الإنجليزي](../README.md)

## كيف تشارك؟

1. استخدم تقسيم البيانات الثابت في الريبو: تدريب 70%، تحقق 15%، واختبار نهائي 15%.
2. درّب النموذج على التدريب فقط، واختر إعداداته باستخدام التحقق.
3. صدّر النموذج بصيغة ONNX وارفعه إلى GitHub Releases.
4. انسخ قالب المشاركة، وأضف اسمك وروابط الأوزان والورقة العلمية والكود والبصمات المطلوبة.
5. عند دمج المشاركة يحسب النظام الدقة تلقائيًا ويحدّث الموقع.

ترتيب التجارب المتجدد يعتمد على **بيانات التحقق**. بعد الاتفاق على نموذج نهائي لكل مشارك، يجرى الاختبار النهائي بشكل منفصل. الدقة هي المقياس الأول، وMacro-F1 يفصل التعادل، مع عرض أداء كل فئة.

الموقع إنجليزي افتراضيًا ويمكن تحويله للعربية. التدريب يعمل على Kaggle، والموقع مستضاف على GitHub Pages. أي دقة تظهر يجب أن تكون محسوبة من نموذج فعلي؛ لا توجد نتائج افتراضية.

بيانات الاختبار الأصلية عامة؛ الفصل هنا التزام بحثي بين الفريق، وليس إخفاءً تقنيًا للصور. لا تضع مفاتيح Kaggle أو GitHub داخل الريبو أو Notebook.
